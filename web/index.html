Take the audio. Leave the platform.

OSMP3 is a small web app you run yourself. Paste a public media URL you have the right to copy, inspect it, and pull a clean MP3. No account, no ads, no cloud locker — the file never stays on the server.

Extractor

Only download media you own or have permission to copy.

MP3 bitrate

01

You paste a URL

The server only accepts public http(s) addresses. Private networks, localhost, and credentialed URLs are rejected.

02

yt-dlp finds the audio

Metadata is read first so you can confirm the title and length. Clips longer than 45 minutes are refused.

03

ffmpeg writes an MP3

The file is streamed back to your browser, then deleted. The API disk is ephemeral; we do not keep a library of other people’s media.

Run it on your own machine

This project is meant to be self-hosted. A public demo is convenient for trying the UI; it is not a license to rip copyrighted catalogs. 

git clone https://github.com/tywish-dev/OpenSourceMp3Downloader.git
cd OpenSourceMp3Downloader
docker build -t osmp3 .
docker run --rm -p 10000:10000 -e PORT=10000 osmp3
